# Sakura Demo

A single-file three.js scene with a cherry tree, ground, rocks, and falling petals.

## Run

```bash
npm start
```

Then open the local server URL printed in the terminal.

If you do not want to use npm, any static server works:

```bash
npx serve .
```

## Notes

- The scene is implemented in [`index.html`](./index.html).
- It uses three.js from a CDN, so there is no build step.
